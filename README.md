# Festival DevOps Music Fest

## Descripción

Proyecto desarrollado para la actividad de aprendizaje de Git y GitHub del programa DevOps y Contenedores Docker.

## Tecnologías utilizadas

* HTML5
* CSS3
* Python
* Flask
* Docker
* Docker Compose
* Git
* GitHub

## Estructura del proyecto

```text
festival-devops/
│
├── frontend/
│   ├── index.html
│   └── style.css
│
├── backend/
│   ├── app.py
│   ├── requirements.txt
│   └── dockerfile
│
├── docker-compose.yml
└── README.md
```

## Control de versiones

Se utilizó Git Flow básico mediante las siguientes ramas:

* main
* feature-landing
* feature-backend
